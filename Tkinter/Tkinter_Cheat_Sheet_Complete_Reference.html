// what is tkinter?

Tkinter is Python's standard built-in GUI library. It lets you create desktop applications with windows, buttons, text, forms and more. No extra installation needed — it ships with Python.

Full name

Tk Interface — wraps the Tk GUI toolkit

Import

import tkinter or from tkinter import Tk

// minimal program
The 3-Line Window ▾
from tkinter import Tk root = Tk() root.mainloop()
What happens

✅ A window appears  ✅ Stays open until closed  ✅ Minimal working GUI

With Title & Size

from tkinter import Tk root = Tk() root.title("My First App") root.geometry("400x300") root.mainloop()

Full Configuration Example

from tkinter import Tk root = Tk() root.title("My Application") # Window title root.geometry("500x400") # Size: 500w × 400h root.geometry("500x400+100+50") # Size + position (x=100, y=50) root.resizable(True, True) # Allow resizing (w, h) root.minsize(300, 200) # Minimum size root.maxsize(1200, 800) # Maximum size root.config(bg="lightblue") # Background color root.mainloop()
Geometry String Format ▾
Pattern

"WIDTHxHEIGHT+X+Y"

WIDTH = window width in pixels
HEIGHT = window height in pixels
X = pixels from left edge (optional)
Y = pixels from top edge (optional)

"400x300" # 400w × 300h, auto position "600x500+100+50" # 600w × 500h, at screen pos (100, 50) "800x600" # 800w × 600h, auto position
Colors & Execution Flow ▾
# Named colors root.config(bg="lightblue") root.config(bg="white") root.config(bg="darkgreen") # Hex codes root.config(bg="#FF5733") root.config(bg="#00FF00")

Program Flow

1. Import tkinter components ↓ 2. Create root window: root = Tk() ↓ 3. Configure window (title, size, bg…) ↓ 4. Add widgets (buttons, labels, etc.) ↓ 5. root.mainloop() ← REQUIRED · keeps window alive
  • mainloop() must be the LAST line and is mandatory
  • Code after mainloop() won't run until the window closes
  • Always create root = Tk() first, before any widgets

Label — Display Text & Images ▾

A Label displays text or images. It is NOT interactive — users cannot click or type into it.

from tkinter import Tk, Label root = Tk() root.title("Label Demo") root.geometry("400x300") # Basic label label = Label(root, text="Hello, World!") label.pack() # Styled label styled = Label( root, text="Styled Label", font=("Arial", 18, "bold"), fg="blue", bg="lightgray", padx=20, pady=10 ) styled.pack() root.mainloop()

// button widget
Button — Clickable Actions ▾

A Button performs an action when clicked. Use the command parameter to link it to a function.

from tkinter import Tk, Button root = Tk() root.geometry("400x300") def my_function(): print("Button clicked!") # Basic button btn = Button(root, text="Click Me", command=my_function) btn.pack() # Styled button styled_btn = Button( root, text="Submit", command=my_function, bg="green", fg="white", font=("Arial", 12, "bold"), padx=20, pady=10 ) styled_btn.pack(pady=10) root.mainloop()

Passing Arguments with Lambda

def greet(name): print(f"Hello, {name}!") # WRONG: This calls greet immediately btn = Button(root, text="Greet", command=greet("Alice")) # ❌ # CORRECT: Use lambda to delay execution btn = Button(root, text="Greet", command=lambda: greet("Alice")) # ✅

Entry — Single-Line Text Input ▾

An Entry lets users type single-line text input into your program.

from tkinter import Tk, Entry, Button, Label root = Tk() root.geometry("400x300") entry = Entry(root, width=30) entry.pack() # Insert default text entry.insert(0, "Type here…") # Password field password = Entry(root, show="*") password.pack() def get_text(): user_input = entry.get() # Retrieve text print(f"You typed: {user_input}") def clear_text(): entry.delete(0, "end") # Clear all text btn = Button(root, text="Submit", command=get_text) btn.pack() root.mainloop()

Text Widget — Multi-line Input ▾

The Text widget provides a multi-line editable text area (unlike Entry which is one line).

from tkinter import Tk, Text, Button, Scrollbar root = Tk() root.geometry("500x400") # Create text widget text = Text(root, height=15, width=50, font=("Arial", 11)) text.pack(padx=10, pady=10) def get_content(): content = text.get("1.0", "end-1c") # "1.0" = line 1, char 0 print(content) def set_content(): text.delete("1.0", "end") text.insert("1.0", "Hello!\nThis is multi-line text.") Button(root, text="Get", command=get_content).pack() Button(root, text="Set", command=set_content).pack() root.mainloop()

Frame — Container / Organizer ▾

A Frame is an invisible container used to group and organize other widgets. Essential for complex layouts.

from tkinter import Tk, Frame, Label, Button root = Tk() root.geometry("500x400") # Top frame top_frame = Frame(root, bg="lightblue", height=80) top_frame.pack(fill="x", padx=10, pady=5) Label(top_frame, text="Header Area", bg="lightblue", font=("Arial", 16)).pack(pady=20) # Bottom frame bottom_frame = Frame(root, bg="lightyellow") bottom_frame.pack(fill="both", expand=True, padx=10) Button(bottom_frame, text="Button 1").pack(side="left", padx=5) Button(bottom_frame, text="Button 2").pack(side="left", padx=5) root.mainloop()
Listbox — Selectable List ▾

A Listbox displays a list of items that users can select from.

from tkinter import Tk, Listbox, Button root = Tk() root.geometry("400x300") listbox = Listbox(root, height=8, width=30) listbox.pack(padx=10, pady=10) # Add items listbox.insert(0, "Apple") listbox.insert(1, "Banana") listbox.insert(2, "Orange") listbox.insert("end", "Grape") # "end" adds to end def get_selection(): selected = listbox.curselection() # Returns tuple of indices if selected: item = listbox.get(selected[0]) print(f"Selected: {item}") else: print("Nothing selected") Button(root, text="Get Selection", command=get_selection).pack() root.mainloop()

Checkbutton — Multiple Selections (IntVar) ▾

A Checkbutton lets users select multiple independent options. Uses IntVar to track state.

from tkinter import Tk, Checkbutton, IntVar, Button root = Tk() root.geometry("400x300") var1 = IntVar() # 1 if checked, 0 if unchecked var2 = IntVar() var3 = IntVar() Checkbutton(root, text="Python", variable=var1, font=("Arial", 12)).pack() Checkbutton(root, text="Java", variable=var2, font=("Arial", 12)).pack() Checkbutton(root, text="C++", variable=var3, font=("Arial", 12)).pack() def get_selections(): selected = [name for name, var in [("Python",var1),("Java",var2),("C++",var3)] if var.get() == 1] print("Selected:", selected) Button(root, text="Get", command=get_selections).pack(pady=10) root.mainloop()
IntVar

var = IntVar()  ·  var.get() → 1 (checked) or 0 (unchecked)  ·  var.set(1) to check programmatically

Radiobutton — Single Selection (StringVar) ▾

A Radiobutton lets users select ONE option from multiple choices. All share the same StringVar.

from tkinter import Tk, Radiobutton, StringVar, Button root = Tk() root.geometry("400x300") # All radiobuttons share ONE variable var = StringVar(value="Python") # Default selection Radiobutton(root, text="Python", variable=var, value="Python").pack() Radiobutton(root, text="Java", variable=var, value="Java").pack() Radiobutton(root, text="C++", variable=var, value="C++").pack() def get_selection(): selected = var.get() print(f"You selected: {selected}") Button(root, text="Get Selection", command=get_selection).pack(pady=10) root.mainloop()
Key Difference

Checkbutton = multiple selections allowed (IntVar per button)
Radiobutton = only ONE selection allowed (one shared StringVar)

StringVar Reference

var = StringVar(value="default") # Create with default var.get() # Get current value var.set("new_value") # Set new value
  • Text = multi-line input (Entry is single-line)
  • Frame = invisible container to group widgets
  • Listbox = selectable list; .curselection() returns tuple of indices
  • Checkbutton + IntVar → multiple independent selections
  • Radiobutton + StringVar → mutually exclusive single selection

Pack stacks widgets in a line (top-to-bottom by default). Simple but limited.

Grid — Professional Table Layout ⭐ ▾

Grid arranges widgets in rows and columns like a spreadsheet. This is the most professional and flexible layout manager.

from tkinter import Tk, Label root = Tk() root.geometry("400x300") # row, column both start at 0 Label(root, text="Cell(0,0)", bg="red", fg="white", width=10, height=3).grid(row=0, column=0) Label(root, text="Cell(0,1)", bg="green", fg="white", width=10, height=3).grid(row=0, column=1) Label(root, text="Cell(1,0)", bg="blue", fg="white", width=10, height=3).grid(row=1, column=0) Label(root, text="Cell(1,1)", bg="orange",fg="white", width=10, height=3).grid(row=1, column=1) root.mainloop()

from tkinter import Tk, Label root = Tk() root.geometry("500x400") Label(root, text="Position 100,50", bg="red", fg="white").place(x=100, y=50, width=150, height=50) Label(root, text="Center (relative)", bg="blue", fg="white").place(relx=0.5, rely=0.5, anchor="center", width=150, height=50) root.mainloop()

Event Binding with .bind() ▾

Events are user actions (click, keystroke, mouse move). Use .bind() to connect events to handler functions.

widget.bind("<Event>", handler_function) # Handler function MUST accept an event parameter def handler(event): print("Event triggered!") print(f"Mouse at: {event.x}, {event.y}") print(f"Key pressed: {event.keysym}")

Mouse Event Reference

EventSyntaxTriggers

Right Click<Button-3>Click right button
Double Click<Double-Button-1>Double click
Mouse Motion<Motion>Mouse moves
Mouse Enter<Enter>Mouse enters widget
Mouse Leave<Leave>Mouse leaves widget

Click Example

from tkinter import Tk, Label root = Tk() root.geometry("400x300") label = Label(root, text="Click on me!", font=("Arial", 14), bg="lightblue") label.pack(pady=20) def on_click(event): label.config(text=f"Clicked at ({event.x}, {event.y})") label.bind("<Button-1>", on_click) root.mainloop()
Keyboard Events ▾
from tkinter import Tk, Label, Entry root = Tk() root.geometry("400x300") entry = Entry(root, font=("Arial", 14), width=30) entry.pack(pady=20) result = Label(root, text="", font=("Arial", 12)) result.pack() def on_key(event): result.config(text=f"You pressed: {event.keysym}") entry.bind("<KeyPress>", on_key) # Any key root.bind("<Return>", lambda e: result.config(text="ENTER!")) # Enter key root.bind("<Escape>", lambda e: root.destroy()) # Escape root.mainloop()

Lambda Functions & Passing Arguments ▾

When you need to pass arguments to a button command, you cannot call the function directly (it executes immediately). Use lambda to wrap it.

def greet(name): print(f"Hello, {name}!") # ❌ WRONG — executes immediately at widget creation btn = Button(root, text="Greet", command=greet("Alice")) # ✅ CORRECT — creates anonymous function, called on click btn = Button(root, text="Greet", command=lambda: greet("Alice"))

Lambda with .bind() and Event Object

from tkinter import Tk, Label root = Tk() root.geometry("400x300") label = Label(root, text="Click me", font=("Arial", 14), bg="lightblue") label.pack(pady=20) def process_click(name, event): label.config(text=f"{name} clicked at X={event.x}, Y={event.y}") # Pass extra arg + event via lambda label.bind("<Button-1>", lambda event: process_click("Label", event)) root.mainloop()

Why Class-Based Architecture? ▾

Classes keep related functions and variables together, making code organized, scalable, and professional.

class NoteApp: def __init__(self, root): # Initialize all state variables self.root = root self.current_file = None self.file_changed = False # Build UI in logical methods self.create_menu() self.create_toolbar() self.create_text_area() self.create_status_bar() self.setup_shortcuts() self.update_status() def create_menu(self): pass def create_toolbar(self): pass def create_text_area(self): pass def create_status_bar(self): pass def setup_shortcuts(self): pass def new_file(self): pass def open_file(self): pass def save_file(self): pass def update_status(self): pass
Benefits of Class-Based Design

✅ Related functionality grouped together
✅ Shared state via self.current_file, self.file_changed
✅ Easy to extend and maintain
✅ Professional, scalable architecture

File I/O Operations ▾

Reading a File

try: with open(file_path, "r") as file: content = file.read() self.text_area.delete("1.0", "end") self.text_area.insert("1.0", content) self.current_file = file_path except FileNotFoundError: messagebox.showerror("Error", "File not found") except Exception as e: messagebox.showerror("Error", f"Cannot open: {str(e)}")

Writing a File
