Events & Functions

Master event binding, keyboard events, mouse events. Learn lambda functions and build an interactive calculator.

// event handling basics

What are Events?

Events are actions that happen in your GUI - clicking buttons, typing, mouse movement, key presses, etc.

Event Flow

User Action → Event Generated → Event Handler Called ↓ ↓ ↓ Click ButtonClick Event my_function() runs Type KeyPress Event another_function() runs Move Mouse Motion Event motion_handler() runs

Two Ways to Handle Events

1. Command Parameter (for buttons, checkbuttons) button = Button(root, text="Click", command=my_function) 2. Bind Method (for any widget, any event) widget.bind("", my_function)
// event binding

Bind Method Syntax

widget.bind("", function)

Common Events

Event Syntax Triggers
Left Mouse Click <Button-1> Click left button
Right Mouse Click <Button-3> Click right button
Double Click <Double-Button-1> Double click
Mouse Motion <Motion> Mouse moves
Mouse Enter <Enter> Mouse enters widget
Mouse Leave <Leave> Mouse leaves widget
Any Key Press <KeyPress> Any key pressed
Enter Key <Return> Enter/Return key
Space Key <space> Space bar

Click Event Example

from tkinter import Tk, Label root = Tk() root.title("Click Event Demo") root.geometry("400x300") label = Label(root, text="Click on me!", font=("Arial", 14), bg="lightblue") label.pack(pady=20) def on_click(event):   label.config(text="You clicked me!") label.bind("", on_click) root.mainloop()
// keyboard events

Key Press Events

from tkinter import Tk, Label, Entry root = Tk() root.title("Keyboard Events") root.geometry("400x300") entry = Entry(root, font=("Arial", 14), width=30) entry.pack(pady=20) result_label = Label(root, text="", font=("Arial", 12)) result_label.pack() def on_key_press(event):   key = event.keysym   result_label.config(text=f"You pressed: {key}") entry.bind("", on_key_press) root.mainloop()

Specific Key Bindings

from tkinter import Tk, Label root = Tk() root.title("Specific Keys") root.geometry("400x300") label = Label(root, text="Press keys", font=("Arial", 16)) label.pack(pady=20) def on_enter(event):   label.config(text="You pressed ENTER!") def on_space(event):   label.config(text="You pressed SPACE!") root.bind("", on_enter) # Enter key root.bind("", on_space) # Space bar root.mainloop()

// lambda functions with arguments

The Problem: Passing Arguments

When you need to pass arguments to button commands, you can't just call the function because it would execute immediately.

Solution: Lambda

def greet(name):   print(f"Hello, {name}!") button = Button(root, text="Greet", command=lambda: greet("Alice")) button.pack()
Lambda Explanation

Lambda is a small function that lets you pass arguments:
lambda: function(argument)
It creates a function on-the-fly that calls your function.

Multiple Buttons Example

from tkinter import Tk, Button root = Tk() root.title("Lambda with Multiple Buttons") root.geometry("400x300") def show_message(message):   print(message) button1 = Button(root, text="Button 1", command=lambda: show_message("Button 1 clicked!")) button1.pack(pady=10) button2 = Button(root, text="Button 2", command=lambda: show_message("Button 2 clicked!")) button2.pack(pady=10) button3 = Button(root, text="Button 3", command=lambda: show_message("Button 3 clicked!")) button3.pack(pady=10) root.mainloop()

Lambda with Both Arguments AND Event Object

from tkinter import Tk, Label root = Tk() root.title("Lambda with Bind and Event") root.geometry("400x300") label = Label(root, text="Click me", font=("Arial", 14), bg="lightblue") label.pack(pady=20) def process_click(name, event):   label.config(text=f"{name} clicked at X={event.x}, Y={event.y}") label.bind("", lambda event: process_click("Label", event)) root.mainloop()

// key takeaways
  • Events are user actions (click, type, move)
  • .bind() connects events to functions
  • Common events: <Button-1>, <Return>, <KeyPress>
  • Lambda lets you pass arguments to commands
  • Event objects contain info about what happened

  • event.keysym = which key was pressed
