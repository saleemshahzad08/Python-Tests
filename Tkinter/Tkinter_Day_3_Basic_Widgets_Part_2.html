Basic Widgets Part 2

Learn Text, Frame, Listbox, Checkbutton, and Radiobutton widgets. Master multi-line input, layout organization, and selection controls.

// text widget

What is a Text Widget?

A Text widget displays and lets users edit multi-line text. Unlike Entry (single line), Text can hold entire paragraphs!

Creating a Simple Text Widget

from tkinter import Tk, Text root = Tk() root.title("Text Widget Demo") root.geometry("400x300") # Simple text widget text = Text(root, height=10, width=40) text.pack() root.mainloop()

Text Widget Methods

Method Purpose Example
.get(start, end) Get text range text.get("1.0", "end")
.insert(position, text) Insert text at position text.insert("1.0", "Hello")
.delete(start, end) Delete text range text.delete("1.0", "end")

Getting Text from Text Widget

from tkinter import Tk, Text, Button root = Tk() root.title("Text Demo") root.geometry("400x300") text = Text(root, height=10, width=40, font=("Arial", 10)) text.pack(pady=10) def get_text():   content = text.get("1.0", "end-1c")   print("Text content:")   print(content) button = Button(root, text="Get Text", command=get_text) button.pack() root.mainloop()
Important Note

"1.0" = line 1, character 0 (start)
"end-1c" = end minus 1 character (removes final newline)

Text Widget Properties

Property Purpose Example
height Height in lines height=10
width Width in characters width=40
font Font styling font=("Arial", 12)
bg Background color bg="white"
fg Text color fg="black"
wrap Word wrap mode wrap="word"
// frame widget

What is a Frame?

A Frame is a container that holds other widgets. It helps organize your layout into sections.

Creating Frames for Organization

from tkinter import Tk, Frame, Label, Button root = Tk() root.title("Multiple Frames") root.geometry("400x400") # Header Frame header_frame = Frame(root, bg="darkblue", height=50) header_frame.pack(fill="x") header_label = Label(header_frame, text="Header Section", font=("Arial", 14, "bold"), fg="white", bg="darkblue") header_label.pack() # Content Frame content_frame = Frame(root, bg="white") content_frame.pack(fill="both", expand=True, padx=10, pady=10) content_label = Label(content_frame, text="Main Content", font=("Arial", 12), bg="white") content_label.pack() # Footer Frame footer_frame = Frame(root, bg="gray", height=50) footer_frame.pack(fill="x") footer_label = Label(footer_frame, text="Footer Section", font=("Arial", 10), fg="white", bg="gray") footer_label.pack() root.mainloop()

Frame Properties

Property Purpose Example
bg Background color bg="lightblue"
height Height in pixels height=100
width Width in pixels width=300
relief Border style relief="raised"
borderwidth Border thickness borderwidth=2
// listbox widget

What is a Listbox?

A Listbox displays a list of items that users can select from.

Creating a Simple Listbox

from tkinter import Tk, Listbox root = Tk() root.title("Listbox Demo") root.geometry("400x300") # Create listbox listbox = Listbox(root, height=8, width=30) listbox.pack(padx=10, pady=10) # Add items listbox.insert(0, "Apple") listbox.insert(1, "Banana") listbox.insert(2, "Orange") root.mainloop()

Listbox Methods

Method Purpose Example
.insert(index, item) Add item listbox.insert("end", "Apple")
.delete(index) Remove item listbox.delete(0)
.get(index) Get item text listbox.get(0)
.curselection() Get selected index selected = listbox.curselection()
.size() Number of items count = listbox.size()

Getting Selected Items

from tkinter import Tk, Listbox, Button root = Tk() root.title("Listbox Demo") root.geometry("400x300") listbox = Listbox(root, height=8, width=30) listbox.pack(padx=10, pady=10) listbox.insert(0, "Apple") listbox.insert(1, "Banana") listbox.insert(2, "Orange") def get_selection():   selected = listbox.curselection()   if selected:     item = listbox.get(selected[0])     print(f"You selected: {item}")   else:     print("No item selected") button = Button(root, text="Get Selection", command=get_selection) button.pack() root.mainloop()
// checkbutton widget

What is a Checkbutton?

A Checkbutton lets users select multiple independent options (like checkboxes in forms).

Creating Checkbuttons

from tkinter import Tk, Checkbutton, IntVar root = Tk() root.title("Checkbutton Demo") root.geometry("400x300") # Variables to store checkbox states var1 = IntVar() var2 = IntVar() var3 = IntVar() # Create checkbuttons check1 = Checkbutton(root, text="Python", variable=var1, font=("Arial", 12)) check1.pack() check2 = Checkbutton(root, text="Java", variable=var2, font=("Arial", 12)) check2.pack() check3 = Checkbutton(root, text="C++", variable=var3, font=("Arial", 12)) check3.pack() def get_selections():   selected = []   if var1.get() == 1:     selected.append("Python")   if var2.get() == 1:     selected.append("Java")   if var3.get() == 1:     selected.append("C++")   print("Selected languages:", selected) from tkinter import Button button = Button(root, text="Get Selection", command=get_selections) button.pack(pady=10) root.mainloop()

Understanding IntVar

var = IntVar() # Create a variable var.get() # Returns 1 if checked, 0 if unchecked var.set(1) # Set to checked var.set(0) # Set to unchecked

Checkbutton Properties

Property Purpose Example
text Label text text="Python"
variable IntVar to store state variable=var1
font Font styling font=("Arial", 12)
onvalue Value when checked onvalue=1
offvalue Value when unchecked offvalue=0
// radiobutton widget

What is a Radiobutton?

A Radiobutton lets users select ONE option from multiple choices (mutually exclusive).

Key Difference

Checkbutton = multiple selections allowed
Radiobutton = only ONE selection allowed

Creating Radiobuttons

from tkinter import Tk, Radiobutton, StringVar, Button root = Tk() root.title("Radiobutton Demo") root.geometry("400x300") # Variable to store selected option var = StringVar(value="Python") # Create radiobuttons (all share same variable!) radio1 = Radiobutton(root, text="Python", variable=var, value="Python", font=("Arial", 12)) radio1.pack() radio2 = Radiobutton(root, text="Java", variable=var, value="Java", font=("Arial", 12)) radio2.pack() radio3 = Radiobutton(root, text="C++", variable=var, value="C++", font=("Arial", 12)) radio3.pack() def get_selection():   selected = var.get()   print(f"You selected: {selected}") button = Button(root, text="Get Selection", command=get_selection) button.pack(pady=10) root.mainloop()

Understanding StringVar

var = StringVar(value="default") # Create with default var.get() # Get current value var.set("new_value") # Set new value

Radiobutton Properties

Property Purpose Example
text Label text text="Python"
variable StringVar (shared by all) variable=var
value Value when selected value="Python"
font Font styling font=("Arial", 12)
// key takeaways
  • Text widget handles multi-line input
  • Frame widget organizes and containers other widgets
  • Listbox displays a selectable list of items
  • Checkbutton allows multiple independent selections
  • Radiobutton allows only ONE selection (mutually exclusive)
  • IntVar stores Checkbutton states (0=unchecked, 1=checked)
  • StringVar stores Radiobutton selected value
  • Listbox.curselection() returns tuple of selected indices
