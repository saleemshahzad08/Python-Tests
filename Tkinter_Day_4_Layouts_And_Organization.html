Layouts & Organization

Master Grid, Pack, and Place layout managers. Learn when to use each, how to combine them, and organize widgets professionally.

// layout managers overview

What are Layout Managers?

Layout Managers control WHERE and HOW widgets appear in your window. There are three main ones: Pack, Grid, and Place.

The Three Layout Managers

Manager Best For Complexity
Pack Simple, linear layouts Easy ⭐
Grid Forms & tables (PROFESSIONAL) Medium ⭐⭐⭐
Place Pixel-perfect positioning Hard ⭐⭐⭐⭐
Critical Rule

DON'T MIX layout managers in the SAME parent!
❌ label.pack() then button.grid() = CHAOS
✅ Use different frames if you need different managers

// pack layout manager

Pack Basics

Pack stacks widgets in a line (top-to-bottom or left-to-right).

Simple Example

from tkinter import Tk, Label root = Tk() root.title("Pack Demo") root.geometry("400x300") label1 = Label(root, text="First", bg="red", fg="white") label1.pack() label2 = Label(root, text="Second", bg="green", fg="white") label2.pack() label3 = Label(root, text="Third", bg="blue", fg="white") label3.pack() root.mainloop()

Result: Widgets stacked vertically (top to bottom)

Pack Parameters

Parameter Values Purpose
side "top", "bottom", "left", "right" Which direction
fill "x", "y", "both", "none" Stretch to fill space
expand True, False Take remaining space
padx integer Left-right padding
pady integer Top-bottom padding
anchor "n", "s", "e", "w", "center" Alignment
// grid layout manager (PROFESSIONAL)

Grid Basics

Grid arranges widgets in rows and columns like a table. This is the MOST PROFESSIONAL layout manager!

Simple Grid Example

from tkinter import Tk, Label root = Tk() root.title("Grid Demo") root.geometry("400x300") label1 = Label(root, text="Cell (0,0)", bg="red", fg="white", width=10, height=3) label1.grid(row=0, column=0) label2 = Label(root, text="Cell (0,1)", bg="green", fg="white", width=10, height=3) label2.grid(row=0, column=1) label3 = Label(root, text="Cell (1,0)", bg="blue", fg="white", width=10, height=3) label3.grid(row=1, column=0) label4 = Label(root, text="Cell (1,1)", bg="orange", fg="white", width=10, height=3) label4.grid(row=1, column=1) root.mainloop()

Result: 2x2 grid of widgets

Grid Parameters

Parameter Purpose Example
row Row number (0-based) row=0
column Column number (0-based) column=1
rowspan Span multiple rows rowspan=2
columnspan Span multiple columns columnspan=3
sticky Alignment within cell sticky="nsew"
padx Left-right padding padx=10
pady Top-bottom padding pady=5

Sticky Parameter (Alignment)

"n" = North (top) "s" = South (bottom) "e" = East (right) "w" = West (left) "ne" = Northeast (top-right) "nsew" = Fill entire cell

Professional Form Example with Grid

from tkinter import Tk, Label, Entry, Button root = Tk() root.title("Grid Form") root.geometry("400x300") title = Label(root, text="Login Form", font=("Arial", 16, "bold")) title.grid(row=0, column=0, columnspan=2, pady=10) name_label = Label(root, text="Username:") name_label.grid(row=1, column=0, sticky="e", padx=10, pady=5) name_entry = Entry(root, width=20) name_entry.grid(row=1, column=1, padx=10, pady=5) password_label = Label(root, text="Password:") password_label.grid(row=2, column=0, sticky="e", padx=10, pady=5) password_entry = Entry(root, width=20, show="*") password_entry.grid(row=2, column=1, padx=10, pady=5) login_button = Button(root, text="Login", bg="green", fg="white", width=10) login_button.grid(row=3, column=0, pady=15, padx=5) cancel_button = Button(root, text="Cancel", bg="red", fg="white", width=10) cancel_button.grid(row=3, column=1, pady=15, padx=5) root.mainloop()
// place layout manager

Place Basics

Place positions widgets at exact pixel coordinates.

Simple Example

from tkinter import Tk, Label root = Tk() root.title("Place Demo") root.geometry("500x400") label1 = Label(root, text="Position 100,50", bg="red", fg="white") label1.place(x=100, y=50, width=150, height=50) label2 = Label(root, text="Position 300,200", bg="blue", fg="white") label2.place(x=300, y=200, width=150, height=50) root.mainloop()

Place Parameters

Parameter Purpose Example
x X coordinate (from left) x=100
y Y coordinate (from top) y=50
width Widget width in pixels width=150
height Widget height in pixels height=50
relx Relative X (0.0 to 1.0) relx=0.5 (center)
rely Relative Y (0.0 to 1.0) rely=0.5 (center)
// key takeaways
  • Pack = stacks widgets in a line (simple)
  • Grid = arranges in table (PROFESSIONAL) ⭐
  • Place = pixel-perfect positioning (precise)
  • DON'T MIX managers in same parent!
  • Grid sticky: "n", "s", "e", "w", "ne", "nsew"
  • Grid columnspan/rowspan for spanning cells
  • Use Frames if you need different managers
