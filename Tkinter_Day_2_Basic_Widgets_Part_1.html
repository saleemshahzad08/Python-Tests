Basic Widgets Part 1

Learn Label, Button, and Entry widgets. Understand widget properties, command functions, and how to get user input.

// what are widgets?

Understanding Widgets

Widgets are interactive elements in your GUI window. Think of widgets as LEGO blocks - each widget does a specific job, and you combine them to build complete interfaces.

Widget Analogy

LEGO blocks are like widgets:
• Each block (widget) has a specific purpose
• You stack them together to create something bigger
• The same block can be used in different ways
• You combine many blocks (widgets) to build complete applications

Widget Hierarchy


Tk() [Main Window]
├─ Label (displays text/images)
├─ Button (clickable)
├─ Entry (single-line text input)
├─ Text (multi-line text)
├─ Frame (container for other widgets)
├─ Listbox (list of items)
└─ ... and many more

Basic Widget Creation Pattern

All widgets follow the same pattern:


widget = WidgetName(parent, property1=value1, property2=value2)
widget.pack() # or .grid() or .place() - makes it visible
Real Example

label = Label(root, text="Hello", font=("Arial", 14))
label.pack()
// label widget

What is a Label?

A Label widget displays text or images on your window. Labels are NOT interactive (users can't click them to perform actions).

Creating a Simple Label


from tkinter import Tk, Label

root = Tk()
root.geometry("400x300")

label = Label(root, text="Hello, World!")
label.pack()

root.mainloop()

Customizing Labels


from tkinter import Tk, Label

root = Tk()
root.geometry("400x300")
root.config(bg="white")

# Label 1: Basic
label1 = Label(root, text="Basic Label")
label1.pack()

# Label 2: With Font
label2 = Label( root, text="Big Bold Text", font=("Arial", 16, "bold") )
label2.pack()

# Label 3: With Colors
label3 = Label( root, text="Colored Label", font=("Courier", 12), fg="white", bg="darkblue" )
label3.pack()

# Label 4: With Padding
label4 = Label( root, text="Padded Label", font=("Arial", 10), bg="lightyellow", padx=20, pady=10 )
label4.pack()

root.mainloop()

Label Properties

Property Purpose Example
text Text to display text="Hello"
font Font styling font=("Arial", 14, "bold")
fg Text color (foreground) fg="red"
bg Background color bg="lightblue"
padx Left-right padding padx=10
pady Top-bottom padding pady=5
width Width in characters width=20
height Height in lines height=2
justify Text alignment justify="center"
relief Border style relief="raised"

Font Format Explained

Font Tuple Pattern

(FontName, Size, Style)

  • FontName: Arial, Courier, Times, Helvetica, Georgia
  • Size: numeric (10, 12, 14, 16, etc.)
  • Style: "bold", "italic", "bold italic", or omit for normal

Font Examples:


font=("Arial", 14) # Size only
font=("Arial", 14, "bold") # Bold
font=("Arial", 14, "italic") # Italic
font=("Arial", 14, "bold italic") # Bold & Italic
// button widget

What is a Button?

A Button is a clickable element that performs an action when clicked.

Creating a Simple Button


from tkinter import Tk, Button

root = Tk()
root.title("Button Demo")
root.geometry("400x300")

def on_click():
print("Button was clicked!")

button = Button(root, text="Click Me!", command=on_click)
button.pack()

root.mainloop()
Important Note

Use command=function_name (WITHOUT parentheses!)

✅ command=on_click — Correct
❌ command=on_click() — Wrong (calls function immediately)

Understanding the command Parameter

The command parameter tells the button what function to run when clicked.


def greet():
print("Hello!")

button = Button(root, text="Say Hello", command=greet)
button.pack()

Button with Arguments (Using Lambda)

What if you want to pass arguments to your function?


def greet(name):
print(f"Hello, {name}!")

# Using lambda to pass arguments

button = Button(root, text="Greet", command=lambda: greet("Alice"))
button.pack()
Lambda Explanation

Lambda is a small function that lets you pass arguments:

lambda: function(argument)

It creates a function on-the-fly that calls your function with specific arguments.

Customizing Buttons


from tkinter import Tk, Button

root = Tk()
root.title("Button Customization")
root.geometry("400x300")

# Button 1: Basic
button1 = Button(root, text="Button 1")
button1.pack()

# Button 2: With styling
button2 = Button( root, text="Styled Button", font=("Arial", 12), fg="white", bg="green", padx=20, pady=10, width=20 )
button2.pack()

# Button 3: With function
def show_message():
print("Button 3 clicked!")

button3 = Button( root, text="Click for Message", command=show_message, bg="blue", fg="white", relief="raised" )
button3.pack()

# Button 4: Disabled button
button4 = Button( root, text="Disabled Button", state="disabled" )
button4.pack()

root.mainloop()

Button Properties

Property Purpose Example
text Button label text="Click"

font Font styling font=("Arial", 12)
fg Text color fg="white"
bg Background color bg="blue"
padx Horizontal padding padx=15

Relief Options

The relief property controls the button's 3D appearance:


relief="raised" # Button appears raised/3D
relief="sunken" # Button appears pressed/indented
relief="flat" # No 3D effect, flat appearance
relief="ridge" # Ridge effect
relief="groove" # Groove effect

What is an Entry?

An Entry widget lets users type text input into your program. It's a single-line text field.

Creating a Simple Entry


from tkinter import Tk, Entry

root = Tk()
root.title("Entry Demo")
root.geometry("400x300")

entry = Entry(root)
entry.pack()

root.mainloop()
Interactive Test

Run the above code and you'll see a text field where you can type!

Getting Text from Entry (.get())


from tkinter import Tk, Entry, Button

root = Tk()
root.title("Entry Demo")
root.geometry("400x300")

entry = Entry(root)
entry.pack()

def get_text():
user_input = entry.get()
print(f"You typed: {user_input}")

button = Button(root, text="Submit", command=get_text)
button.pack()

root.mainloop()

Customizing Entry


from tkinter import Tk, Entry, Button, Label

root = Tk()
root.title("Entry Customization")
root.geometry("400x300")

# Entry 1: Basic with width
label1 = Label(root, text="Name:")
label1.pack()

entry1 = Entry(root, width=30)
entry1.pack()

# Entry 2: With default text
entry2 = Entry(root)
entry2.insert(0, "Type here...") # 0 = position, then text
entry2.pack()

# Entry 3: Password field (masked)
entry3 = Entry(root, show="*") # Shows asterisks instead of text
entry3.pack()

# Getting values from all entries
def collect_data():
name = entry1.get()
text = entry2.get()
password = entry3.get()
print(f"Name: {name}, Text: {text}, Password length: {len(password)}")

button = Button(root, text="Collect", command=collect_data)
button.pack()

root.mainloop()

Entry Methods

Method Purpose Example
.get() Get text from entry text = entry.get()
.insert() Insert text at position entry.insert(0, "Hello")
.delete() Delete text range entry.delete(0, "end")

Entry Properties

Property Purpose Example
width Width in characters width=30
font Font styling font=("Arial", 12)
fg Text color fg="black"
bg Background color bg="white"
show Mask character (for passwords) show="*"
state "normal" or "disabled" state="normal"
// practical example

Simple Form with All 3 Widgets


from tkinter import Tk, Label, Entry, Button

root = Tk()
root.title("User Registration Form")
root.geometry("400x300")
root.config(bg="lightgray")

# Title
title = Label(root, text="Registration Form", font=("Arial", 18, "bold"), bg="lightgray")
title.pack(pady=10)

# Name Label & Entry
name_label = Label(root, text="Name:", bg="lightgray", font=("Arial", 10))
name_label.pack()

name_entry = Entry(root, width=30, font=("Arial", 10))
name_entry.pack(pady=5)

# Email Label & Entry
email_label = Label(root, text="Email:", bg="lightgray", font=("Arial", 10))
email_label.pack()

email_entry = Entry(root, width=30, font=("Arial", 10))
email_entry.pack(pady=5)

# Password Label & Entry
password_label = Label(root, text="Password:", bg="lightgray", font=("Arial", 10))
password_label.pack()

password_entry = Entry(root, width=30, font=("Arial", 10), show="*")
password_entry.pack(pady=5)

# Submit Button
def submit_form():
name = name_entry.get()
email = email_entry.get()
password = password_entry.get()
if name and email and password:
print(f"Name: {name}")
print(f"Email: {email}")
print(f"Password: {'*' * len(password)}")
print("Form submitted!")
else:
print("Please fill all fields!")

submit_button = Button(root, text="Submit", command=submit_form, bg="green", fg="white", font=("Arial", 12), padx=20, pady=10)
submit_button.pack(pady=15)

root.mainloop()
// key takeaways
  • Widgets are interactive elements in your GUI
  • Label displays text (not interactive)
  • Button performs actions when clicked (use command parameter)
  • Entry gets single-line text input from users (use .get() to retrieve)
  • All widgets follow the same creation pattern
  • Font tuple format: (Name, Size, Style)
  • Use lambda to pass arguments to button commands
  • Common properties: text, font, fg, bg, padx, pady, width, height
